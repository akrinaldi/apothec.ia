
This is the file repository for examples scripts and a Python interpreter for an esoteric programming language called apothec.ia. This language was created by me as part of my dissertation work at North Carolina State University. The language is designed to incorporate theories of posthumanism into its framework, pointing to the dissonance of expectations of code results with actuality given the (sometimes) hidden agency of the machine interpreter. Here, it is not so hidden.

The creation of this project caused me endless amounts of mental suffering. Enjoy.
